# Health Navigation and Management System

## 📌 Project Overview
The **Health Navigation and Management System** is a web-based healthcare management platform 
designed to streamline interactions among administrators, hospitals, doctors, and patients. 
The system ensures efficient healthcare service delivery through structured user roles, 
secure data handling, and dashboard-based navigation.

This project has been developed as an academic system design and implementation project, 
focusing on real-world healthcare workflows, role-based access control, and modular architecture.

---

## 👥 Types of Users
The system supports four different types of users:

1. **Admin**
2. **Patient**
3. **Hospital**
4. **Doctor**

Each user type has specific responsibilities and access privileges within the system.

---

## 🔐 Common Features (Available to All Users)

### 🔑 Authentication
- User registration
- Login to the system
- Logout from the system

### 👤 Account Management
- Change or reset password
- View profile information
- Edit profile details
- Delete account (if applicable)

### 📊 Dashboard
- Access a personalized dashboard after successful login
- View role-specific information and actions

---

## 🏗️ System Architecture
The project follows the **MVC (Model–View–Controller)** architecture to ensure scalability, 
maintainability, and clean separation of concerns.
